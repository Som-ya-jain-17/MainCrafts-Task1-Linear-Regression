# MainCrafts Task 1 – California Housing Price Predictor

## About the Project

This project was developed as part of the Artificial Intelligence & Machine Learning Internship Task 1 at MainCrafts Technology.

The objective of this project is to build and evaluate a Linear Regression model for predicting house values using the California Housing dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset

The California Housing dataset provided by scikit-learn was used.

The dataset contains 20,640 samples and 8 input features:

- MedInc
- HouseAge
- AveRooms
- AveBedrms
- Population
- AveOccup
- Latitude
- Longitude

The target variable is `MedHouseVal`.

## Machine Learning Workflow

The project follows these steps:

1. Data Loading
2. Data Exploration
3. Missing Value Analysis
4. Exploratory Data Analysis
5. Correlation Analysis
6. Train-Test Split
7. Linear Regression Model Training
8. Prediction
9. Model Evaluation
10. Residual Analysis
11. Model Improvement Discussion

## Evaluation Metrics

The model was evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
